## 🎯 What This Does
This workflow helps you generate **production-ready websites, apps, SaaS products, dashboards, and software prototypes** using AI tools.

Instead of writing prompts manually:

✅ Use a **Meta Prompt**  
✅ Let Claude refine your idea  
✅ Get a final optimized prompt  
✅ Generate your software using AI coding tools  

---

# 🔥 Quick Start

### Step 1: Copy Meta Prompt
Click below:

👉 **[Meta Prompt Repository](https://github.com/TechArcanist/Prompt-Generator/blob/main/prompt.md)**

Copy the prompt from `prompt.md`

---

### Step 2: Open Claude
Go to:

👉 **https://claude.ai**

Paste the copied prompt.

---

### Step 3: Answer Questions
Claude will ask things like:

- What are you building?
- Who is your target audience?
- Required features?
- UI design style?
- Authentication needed?
- Database needed?
- Deployment preferences?

Answer properly.

---

### Step 4: Get Final Prompt
Claude generates a **final optimized prompt**

Copy it.

---

### Step 5: Paste Into AI Coding Platforms

Choose any platform below:

| Platform | Link |
|----------|--------|
| Antigravity | https://antigravity.dev |
| Cursor AI | https://www.cursor.com |
